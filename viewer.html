    StudioViewer

    A web viewer for Capture One's Live for Studio. It connects to the Live for Studio server that Capture One runs on this Mac and shows the shared session in any web browser: on this Mac, a client monitor, a laptop, or a phone or tablet on the same network. No iPad app needed.

    What it does

    • Browse the folders Capture One shares, as a large view, filmstrip or grid.
    • Follow the shoot live: each new capture appears as soon as Capture One has it.
    • Zoom to actual size (100%) to check focus, loading only the part on screen.
    • Rate and color-tag images; changes go straight back into Capture One.
    • See aperture, shutter speed and ISO for each frame.
    • Sort by date or name, and filter by rating and color tag.
    • Compare two photos side by side.
    • Present the shoot live to a client monitor: full screen, just the photo.
